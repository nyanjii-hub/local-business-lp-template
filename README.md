# Local Business LP Template

🚀 Demo
https://local-business-lp-template.vercel.app

地域店舗向けのシンプルなランディングページテンプレートです。美容院、整体院、ネイルサロン、エステ、学習塾、士業、工務店などの小規模事業者向けに使えます。

## 特徴

- スマホファーストのレスポンシブ対応
- LINE予約、電話予約、Instagram導線
- 画面下部の固定CTA
- メニュー、口コミ、店舗情報、Google Mapセクション
- HTML/CSS/JavaScriptのみで動作
- Vercel / Netlify / GitHub Pages にそのまま公開可能

## 使い方

1. `index.html` を開く
2. 以下の項目を自分の店舗情報に変更する
3. GitHubにアップロード
4. Vercel / Netlify / GitHub Pages で公開

## 変更する主な箇所

| 項目 | 検索する文字 | 変更例 |
|---|---|---|
| 店舗名 | `Your Salon` / `Your Shop` | `美容室サンプル` |
| 電話番号 | `000-0000-0000` / `0000000000` | `03-1234-5678` / `0312345678` |
| LINE | `@your_line_id` | `@sample_salon` |
| Instagram | `your_account` | `sample_salon` |
| 住所 | `東京都〇〇区〇〇 1-2-3` | 実際の住所 |
| メニュー | `カット` など | 自店舗のメニュー |
| 料金 | `¥4,200` など | 自店舗の料金 |
| 営業時間 | `平日 10:00〜19:00` など | 自店舗の営業時間 |

## Google Mapについて

このテンプレートではAPIキー不要の埋め込みURLを使っています。

```html
https://www.google.com/maps?q=東京都〇〇区〇〇%201-2-3&output=embed
```

住所部分を店舗住所に変更してください。

## 注意

- 画像はUnsplashの外部画像を使用しています。商用利用時は必要に応じて自店舗写真に差し替えてください。
- 口コミ文はサンプルです。実際の口コミを掲載する場合は、掲載許可や引用ルールを確認してください。
- 電話番号、LINE、Instagram、住所は公開前に必ず差し替えてください。
